FORGE — BRAND KIT
Updated 31 August 2026. Supersedes every earlier copy.

This file is a readable mirror of src/forge-theme.css. That file is the source
of truth; if the two ever disagree, the CSS is right and this is stale.


────────────────────────────────────────────────────────────────────────────
1. THE ONE RULE
────────────────────────────────────────────────────────────────────────────

Nothing in Forge names a colour. Everything names a ROLE, and the role
resolves to a value based on the active theme.

    background: var(--surface-1);     ← correct
    background: #131a18;              ← wrong, even if it looks identical

There are exactly two places in the app that contain colour literals:
forge-theme.css (which defines the roles) and appearance.css (whose swatches
must preview a theme the page is NOT currently in, so they cannot use
variables). Everything else — 45 stylesheets — is roles only.


────────────────────────────────────────────────────────────────────────────
2. THREE STATES
────────────────────────────────────────────────────────────────────────────

Settings → Appearance offers three tones, and nothing else:

    Light      always light
    System     follows the device, and changes with it at sunset
    Dark       the original Forge — volt on carbon

How the choice reaches CSS:

    <html data-theme="light">    the athlete chose light
    <html data-theme="dark">     the athlete chose dark
    <html>  (no attribute)       System — prefers-color-scheme decides

Dark is declared TWICE in forge-theme.css: once under
@media (prefers-color-scheme: dark) guarded by :root:not([data-theme="light"]),
and once under :root[data-theme="dark"]. The first makes System follow the OS;
the second makes an explicit dark choice beat a light OS. A token that exists
in only one of those blocks is a bug.

Stored under localStorage key `forge-appearance-v3`, and mirrored to the
athlete's account so a new phone opens looking the same. index.html reads that
key inline before first paint so there is no white flash on a cold open.

Brand colours the athlete can pick — an accent laid on top of these three
tones — are the NEXT step, not part of this.

3. COLOUR
────────────────────────────────────────────────────────────────────────────

                          LIGHT          DARK
BRAND
  --accent                #d7ff45        #d7ff45     the volt. Never flips.
  --accent-ink            #0e1305        #0e1305     text ON the accent
  --accent-text           #3f6212        #d7ff45     accent used AS text
  --accent-dim            #a8c94a        #9fbf3c
  --accent-wash           rgba(120,160,30,.10)   rgba(215,255,69,.08)
  --accent-wash-strong    rgba(120,160,30,.18)   rgba(215,255,69,.16)
  --tint                  #78a01e        #d7ff45     hue that washes mix FROM

  The volt is a FILL colour. As TEXT on a light ground it measures 1.2:1 and
  is unreadable, which is why --accent-text exists: same hue, dark enough to
  read. In dark they are the same value, which is why this only looks like an
  extra token from the light side.

  --tint is the same idea for translucent washes. A 7% volt wash on carbon is
  a faint glow; the identical mix on white is weak yellow bile. Mixing from
  --tint gives a green hint on white and the glow on carbon.

INVERTED SURFACES — tooltips and toasts sit ON TOP of content and want to
contrast with it rather than match it, so they flip with the theme
  --inverse-surface       #14150f        #eef4f1
  --inverse-ink           #f4f4f1        #0a0e0d

DEPTH
  --shadow-1              0 1px 2px rgba(20,21,15,.06)   0 1px 2px rgba(0,0,0,.40)
  --shadow-2              0 6px 18px rgba(20,21,15,.09)  0 6px 20px rgba(0,0,0,.45)
  --shadow-3              0 18px 44px rgba(20,21,15,.16) 0 18px 48px rgba(0,0,0,.60)
  --shadow-color          rgba(20,21,15,.14)             rgba(0,0,0,.45)
  --overlay               rgba(20,21,15,.38)             rgba(0,0,0,.66)
  --scrim                 rgba(20,21,15,.46)             rgba(0,0,0,.72)
  --lift                  #14150f        #ffffff
  --page-glow             transparent    var(--accent-wash)

  --lift is the tint mixer. Several components lift a surface by mixing WHITE
  into it, which separates on carbon and does nothing on white. --lift is
  whichever direction actually separates, so
  `color-mix(in srgb, var(--surface-1) 96%, var(--lift))` reads in both.

  --page-glow is the ambient wash behind the page. On carbon it is the volt
  catching the top-right corner; on white the same wash reads as a stain, so
  light gets none.

BRAND COLOURS THAT ARE NOT OURS — never tokenised, never theme-flipped

4. TYPE
────────────────────────────────────────────────────────────────────────────

  --display   'Archivo', 'Helvetica Neue', Arial, sans-serif
  --body      'Inter', system-ui, -apple-system, sans-serif

Loaded in index.html <head>, with preconnect to fonts.gstatic.com:
  Archivo   500 600 700 800
  Inter     400 500 600 700 800

WHY. Barlow Condensed, set uppercase at 800, was doing a lot of shouting — a
sports-poster face that made every heading feel like a race bib. Archivo is a
grotesque built for headlines AND small text: squarer, more engineered, with
real mass at 700–800 without narrowing. It reads as equipment, which is the
right register for an app whose whole claim is that it tells you the truth
about your training.

Inter stays for body and data. It has the best tabular figures of any free UI
face, and this app is mostly numbers in columns.

USAGE
  Display    page titles, big numbers, metric values, avatar initials.
             800 weight, uppercase, letter-spacing .01–.02em.
  Body       everything else. 400–600.
  Eyebrows   11px, 800, letter-spacing .14em, uppercase, --ink-2.
  Data       Inter with font-variant-numeric: tabular-nums.

Inputs never go below 16px — anything smaller makes iOS Safari zoom the page.

────────────────────────────────────────────────────────────────────────────
6. THE MARK
────────────────────────────────────────────────────────────────────────────

.brand-mark is a mask, not an image: the shape comes from --forge-mark and the
colour from `background: var(--accent-text)`. That is deliberate — a solid volt
mark on white is a smudge, and --accent-text is the same hue at a value that
survives both grounds.

The wordmark is FORGE, --display 800, letter-spacing .1em.

The app icon is unresolved and is NOT covered by this file.


────────────────────────────────────────────────────────────────────────────
7. LEGACY ALIASES
────────────────────────────────────────────────────────────────────────────

Older stylesheets read these. They point at the new roles so nothing had to be
converted twice. Do not use them in new code.

  --panel → --surface-1      --text  → --ink        --gold → --accent
  --panel-2 → --surface-2    --muted → --ink-2      --mint → --good
  --line, --border → --hairline                     --card → --surface-1
  --success → --good         --warning → --warn     --radius-ui → --r-md
  --accent-contrast → --accent-ink
